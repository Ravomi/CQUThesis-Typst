# 学术图表与公式规范

## 1. 三线表（Three-Line Table）
- 优先使用模板内置的 `three-line-table(...)` 函数：顶线与底线粗（1.2pt），栏目线细（0.6pt），无竖线。
- **表题置顶，图题置底**：所有图表必须在正文中先提及（如“如 @tab-perf 所示”）再出现。
- 数值列统一有效数字位数与单位（单位标注在表头括号内，如 `平均耗时 (s)`）。

## 2. 插图与公式
- 矢量图优先（SVG/高分辨率 300 DPI PNG），图中字号与正文小四号协调，避免模糊或截断。
- 数学变量用斜体（如 `$x_i$`），专有下标/算子用正体（如 `$T_"total"$`），全篇符号与 `contents/denotation.typ` 符号表严格一致。
