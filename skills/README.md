# 论文写作与排版 Agent Skills

本目录收录了一套面向学位论文写作与 Typst 排版的精选 Agent Skills（遵循标准 `SKILL.md` 规范，可直接用于 Claude Code、Codex、Cursor、Pi、Antigravity 等 AI 编程助手）。

## Skill 列表

| Skill 目录 | 适用场景 |
| --- | --- |
| [`typst-basics/`](typst-basics/SKILL.md) | Typst 0.14+ 语法速查、LaTeX 对照、数学公式、`set/show` 样式与排错 |
| [`cqu-thesis-typst/`](cqu-thesis-typst/SKILL.md) | 重庆大学 Typst 学位论文排版、盲审检查与编译排错 |
| [`academic-writing-zh/`](academic-writing-zh/SKILL.md) | 中文/双语学术论文写作、摘要四要素、去 AI 味与逻辑润色 |
| [`bibtex-gbt7714-audit/`](bibtex-gbt7714-audit/SKILL.md) | GB/T 7714—2015 参考文献格式校验、BibTeX 清洗与引用核对 |
| [`academic-figures-tables/`](academic-figures-tables/SKILL.md) | 学术三线表、数学公式符号统一与图表题注排版规范 |

## 使用方式

将 `skills/` 下的任意子目录复制到你的 Agent Skills 目录（例如 `~/.agents/skills/` 或项目级 `.agents/skills/`）即可自动生效。
